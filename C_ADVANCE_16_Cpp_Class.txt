-------static properti

- trường hợp properti được khi báo trong hàm thì nó sẽ được lưu trong Stack(tạm thời)-> các biến của nó cũng là tạm thời -> khi khia báo static thì biến sẽ k phụ thuộc vào đối tượng object
- muốn sử dụng static properti ở trong class thì phải cấp phát địa chỉ cho properti này
ví dụ:
class SinhVien{static int x};
SinhVien::x;//cấp phát toàn cục vùng nhớ cho biến X

- static method: static void show();
->chỉ cho phép tương tác với static
-> có thể gọi trực tiếp từ class mà k thông qua đối tượng : SinhVien::show();
